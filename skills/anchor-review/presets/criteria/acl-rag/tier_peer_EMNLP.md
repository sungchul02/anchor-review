# 심사 기준: EMNLP 2027 (peer 등급, ARR 경유)

근거: 결과가 알려진 RAG·문맥 선택 분야 논문 분석 4묶음이다.
- MAIN 12편 (ACL·EMNLP·NAACL 본회의가 섞여 있음)
- FINDINGS 12편
- COLING 6편
- ARXIV-ONLY 12편

"n/12"는 해당 묶음에서 그 특징을 보인 편수다. 분석은 EMNLP와 ACL을 따로 나누지 않았다. 따라서 아래의 EMNLP 특유 강조점은 CFP 문구에서 온 것이고, 표본에서 따로 확인한 것이 아니다.

## 1. 이 학회의 기준선

- 채택률:
  - EMNLP 2025: 본회의 22.16%(1,811편), Findings 17.34%(1,417편), 제출 8,174편. 출처: 공식 front matter(aclanthology.org/2025.emnlp-main.0.pdf).
  - EMNLP 2026: 본회의 약 15%, Findings 약 14%. 비공식 2차 보도이고 공식 보고서는 확인되지 않았다.
  - 따라서 범위는 본회의 15–22%, Findings 14–17%로 본다.
- 점수 의미: 4 = 본회의, 3 = Findings, 2 이하 = 재제출.
- CFP 강조점(EMNLP 2026): 진보를 "fractional improvements in benchmark scores"만으로 재지 않는다. 신뢰성, 강건성, 실행 가능한 통찰을 요구한다.
- 결과 묶음과의 대응:
  - MAIN 같은 논문은 4를 받는다. 단, 여러 모델과 설정에 걸친 강건성이 보여야 한다.
  - FINDINGS 같은 논문은 3을 받는다.
  - COLING 같은 논문은 2.5–3이다.
  - ARXIV-ONLY 같은 논문은 2–2.5다.

## 3. 이 학회에서 결정적이었던 특징

- 여러 모델 계열이나 검색기에서 같은 방향의 이득 → 본회의 쪽.
  - 근거: MAIN은 9/12가 리더 2계열 이상이고 3/12가 5종 이상이다. ARXIV-ONLY에서는 생성기가 사실상 1개인 논문이 5/12다.
  - EMNLP의 강건성 요구와 가장 잘 맞는 축이다.
- 현상을 정량화하고 그것이 실제 정확도 하락과 연결됨을 보임 → 본회의.
  - 근거: MAIN의 분석형과 동기 실험(8/12).
- 비용·효율을 실제로 측정함 → 3 이상의 거의 필수 조건.
  - 근거: MAIN 9/12, FINDINGS 10/12가 측정했다. ARXIV-ONLY는 8/12가 주장만 하고 측정하지 않았다.
- 같은 설정에서 강한 동류 기준선과 비교함 → 4와 3을 가름.
  - 근거: MAIN 7/12가 강한 최신 기준선을 포함했다. FINDINGS는 4/12에서 최강 동류가 빠졌다.
- 통제 설정만 쓴 것 자체는 탈락 사유가 아니었다.
  - 근거: MAIN 6/12가 합성·통제 설정 위주였다.
  - 다만 EMNLP 기준에서는 실제 검색이나 긴 문서 설정을 하나 추가하는 것이 4를 받쳐 준다.

## 4. 탈락 쪽 신호 (ARXIV-ONLY 전형)

결정적 후보(채택 논문 30편에서 관찰되지 않음):
- 비공개·미기술 데이터만 사용 (2/12)
- 재현 정보 누락 (3/12)
- 지표 정의상 불가능한 값, 초록과 표의 불일치
- 주장 미지지 (1/12)

ACL·EMNLP 계열에서는 탈락 신호였지만 COLING에는 1편 있었던 것:
- 주 데이터셋 1–2개 (ARXIV 4/12; MAIN·FINDINGS 0/24; COLING 1/6)

채택 논문에도 흔했던 것(단독으로는 약한 사유):
- 분산이나 유의성 부재
- 작은 이득 (MAIN 6/12, FINDINGS 8/12)
- 과장
- 기준선 수치 복사 (MAIN 3/12)
- 직접 경쟁자 누락 (MAIN 5/12)
- 9B 이하 모델만 사용 (MAIN 5/12)

정도 차이가 있었던 것:
- 효율 주장을 측정하지 않음 (ARXIV 8/12 대 MAIN 소수)
- 절제가 주장과 모순됨 (ARXIV 5/12 대 MAIN 1편)
- 학습 자원·연산의 비대칭 (ARXIV 4/12; MAIN에서도 이득 원천이 섞인 사례 5/12)

주의할 점: ARXIV-ONLY는 미제출 논문을 포함할 수 있다. 위 대응은 상관 관찰이다.

## 5. 주의

- H1–H17은 계속 무효다. 특히 다음을 이유로 감점하지 않는다: 너무 단순함(H7), 놀랍지 않음(H1), 추가 실험 요구를 reject 사유로 쓰기(H13), 주장과 무관한 폐쇄형 모델 비교 요구(H14), Limitations를 그대로 약점으로 옮기기(H16).
- 저자가 SOTA를 주장하지 않았다면 SOTA 미달은 사유가 아니다(H5). "강건성 요구"도 저자 주장의 범위 안에서 적용한다. 강건성을 주장하지 않은 논문에 그 실험을 reject 사유로 요구하지 않는다(H13).
- 심각도를 보정한다.
  - major는 핵심 주장을 무효화할 때만 붙인다.
  - Soundness 2 이하이면 3 이상을 주지 않는다.
  - 점수는 본문에 적은 결함으로 뒷받침한다(I3).
  - 분포를 보정한다: 4는 15–22%, 3 이상은 약 35–40%.
- 표본이 묶음당 12편(COLING 6편)이라 작다. 경계 판정에서는 공식 기준을 우선한다.
