# 심사 기준: COLING 2027 (lower 등급)

근거: 결과가 알려진 RAG·문맥 선택 분야 논문 분석 4묶음이다.
- MAIN 12편
- FINDINGS 12편
- COLING 6편 (COLING 2025 본회의 채택)
- ARXIV-ONLY 12편

COLING 묶음은 **6편뿐이라** 이 등급에 고유한 근거가 가장 얇다. 아래 "n/6"은 6편 중 편수다.

## 1. 이 학회의 기준선

- 채택률: COLING 2025는 760편 채택, 30.1%다(공식 front matter). 장편 논문은 약 32%다. Findings 트랙은 없다.
- 점수 의미(이 등급 전용):
  - 4 = 채택
  - 3.5 = 경계 채택
  - 3 = 풀이 약할 때만 채택
  - 2.5 = 약한 거절
  - 2 이하 = 거절
- 비교 대상은 ACL이 아니라 전형적인 COLING 제출 풀이다.
- 결과 묶음과의 대응:
  - MAIN 같은 논문과 대부분의 FINDINGS 같은 논문은 4를 받는다.
  - COLING 같은 논문은 다수가 3.5–4다. major 결함이 겹치면 3이다.
  - ARXIV-ONLY 상위권(같은 설정 재실행, 데이터 여러 개)은 COLING 예시와 증거 폭이 비슷해 3 근처다.
  - ARXIV-ONLY 하위권(검증 불가, 지표 이상)은 2 이하다.

## 3. 이 학회에서 결정적이었던 특징

- 명확한 문제 진술 하나와 간단한 해결책·자원 하나 → 채택 (COLING 6/6). 진전 크기는 작아도 된다(6/6 점진적).
- 같은 검색 결과와 같은 리더로 공정하게 비교하고 주장이 표와 맞음 → 4 (COLING 1/6, 유일하게 major 결함이 없음).
- "모델이 자기에게 부족한 것을 안다" 류의 동기를 예비 실험으로 먼저 보임 → 채택 쪽 서사 (COLING 4/6, 그중 예비 실험이 있는 구조 2/6).
- 벤치마크·평가 자원 논문은 방법 기준선 없이도 채택됐다 (2/6). 단, 모델 간 비교로 그 자리를 대체했다.
- 상용 API 모델 하나로 주 실험을 해도 채택됐다 (3/6). ACL·EMNLP 묶음보다 모델 폭 요구가 낮다.

## 4. 탈락 쪽 신호 (ARXIV-ONLY 전형)

결정적 후보(채택 논문 30편에서 관찰되지 않음):
- 비공개·미기술 데이터만 사용 (2/12)
- 데이터나 학습 절차 누락으로 검증 불가 (3/12)
- 지표 정의상 불가능한 값, 초록과 표의 수치 불일치
- 주장 미지지 (1/12)

COLING 채택 논문에도 있었던 것(이 등급에서는 단독 탈락 사유가 아님):
- 단일 데이터셋 (1/6)
- 주 실험 단일 모델 (3/6)
- 기준선 인용 수치 (1/6)
- 최신 경쟁자 누락 (3/4 방법 논문)
- 분산 없음 (6/6)
- 과장 (6/6)
- 원고 품질 문제 (4/6)
- 일부 데이터셋에서 열세 (4/6)

정도 차이가 있었던 것:
- 효율 주장을 측정하지 않음: ARXIV 8/12, COLING 3/6
- 절제가 주장과 모순됨: ARXIV 5/12. COLING에서는 효과가 데이터셋별로 혼재한 사례 1편이 있었다.

솔직한 평가:
- COLING 예시와 ARXIV-ONLY 상위 4편은 증거 수준에서 잘 구분되지 않는다.
- ARXIV-ONLY에는 제출하지 않은 논문이 섞여 있을 수 있다.
- 따라서 2.5와 3.5 사이 판정의 신뢰도는 낮다.

## 5. 주의

- H1–H17은 계속 무효다. 특히 다음을 이유로 감점하지 않는다: 너무 단순함(H7), 주제가 좁음(H9), 선행 문헌 없이 새롭지 않다고 하기(H3), 추가 실험을 reject 사유로 쓰기(H13), Limitations를 그대로 옮기기(H16).
- 저자가 SOTA를 주장하지 않았다면 SOTA 미달은 사유가 아니다(H5).
- 심각도를 보정한다.
  - major는 핵심 주장을 무효화할 때만 붙인다.
  - 점수는 본문의 구체적 결함으로 뒷받침한다(I3).
  - 분포를 보정한다: 4와 3.5를 합쳐 약 30%.
- 근거 표본이 6편이다. 이 파일의 COLING 고유 판단은 약한 사전 정보로만 쓰고, 공식 기준(sound하고 재현 가능하면 채택권)을 우선한다.
