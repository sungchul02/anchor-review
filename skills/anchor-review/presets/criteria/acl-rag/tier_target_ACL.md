# 심사 기준: ACL 2027 (target 등급, ARR 경유)

근거: 결과가 알려진 RAG·문맥 선택 분야 논문 분석 4묶음 — MAIN 12편, FINDINGS 12편, COLING 6편, ARXIV-ONLY 12편. 아래 "n/12"는 해당 묶음에서 그 특징을 보인 편수다.

## 1. 이 학회의 기준선

- 채택률: 본회의 18.9%(2,296편), Findings 17.8%(2,163편), 제출 12,148편. 출처: ACL 2026 공식 front matter(aclanthology.org/2026.acl-long.0.pdf). 합계 약 35–40%(COPR 2025-01 보고서).
- 점수 의미: 4 = 본회의, 3 = Findings, 2 이하 = 이번 사이클 불가(재제출).
- 결과 묶음과의 대응:
  - MAIN 같은 논문만 4를 받는다.
  - FINDINGS 같은 논문은 3을 받는다. 그중 상위(강한 진전, 과장 적음)는 3.5다.
  - COLING 같은 논문은 대체로 2.5–3이다. 6편 중 major 결함이 없는 것은 1편뿐이고, 3편은 주 실험이 API 모델 하나다.
  - ARXIV-ONLY 같은 논문은 2–2.5다.
- MAIN과 FINDINGS의 증거 차이는 생각보다 작다. 둘 다 점진적 변형이 10/12이고 분산 보고는 거의 없다. 판정은 아래 3절의 특징으로 가르되, 확신은 낮게 둔다.

## 3. 이 학회에서 결정적이었던 특징

- 짧은 예비 실험이나 현상 정량화가 문제를 먼저 보이고 방법이 뒤따른다 → 본회의 쪽 (MAIN 8/12; FINDINGS에서는 2/12만 프레이밍이 주 기여).
- 같은 설정에서 돌린 기준선이 거의 전부다 → 본회의 (MAIN 11/12). FINDINGS는 조건 불일치가 6/12다.
- 서술 과장 정도: 강한 과장은 MAIN 2/12, FINDINGS 7/12다. 과장이 클수록 3 쪽이다.
- 강한 진전(압축률 대비 거의 무손실, 장문맥 일반화)이나 측정 틀 제안 → 4 이상이 확실하다 (MAIN 2/12). FINDINGS의 강한 진전 1편은 기준선 조건 불일치 때문에 3에 머물렀다.
- 리더 5종 이상, 다중 검색기, 실제 긴 문서처럼 범위를 넓힘 → 4를 받쳐 줌 (MAIN 5/12).
- 공통 하한: 표준 벤치마크 3개 이상, 단순 기준선 대비 뚜렷한 이득, 절제 1개 이상. 세 묶음 채택 논문 모두 이 하한을 지켰다.

## 4. 탈락 쪽 신호 (ARXIV-ONLY 전형)

결정적 후보(채택 논문 30편에서 관찰되지 않음):
- 비공개이거나 구축이 기술되지 않은 데이터만 씀 (2/12)
- 데이터·학습·평가셋 정보 누락으로 검증 불가 (3/12)
- 정의상 불가능한 지표값, 초록과 표의 수치 불일치 (다수가 8/12에 포함)
- 주장이 지지되지 않음 (1/12)

ACL에서는 탈락 신호였지만 COLING에는 1편 있었던 것:
- 주 데이터셋 1–2개 (ARXIV 4/12; MAIN·FINDINGS 0/24; COLING 1/6)

채택 논문에도 있었던 것(단독으로는 감점 근거가 약함):
- 분산이나 유의성이 없음 (채택 논문 대부분)
- 작은 이득 (ARXIV 6/12, MAIN 6/12, FINDINGS 8/12)
- 과장된 서술 (전 묶음)
- 기준선 수치 복사 (ARXIV 5/12, MAIN 3/12)
- 직접 경쟁자 누락 (ARXIV 9/12, MAIN 5/12, FINDINGS 4/12)
- 9B 이하 모델만 사용 (MAIN 5/12)
- 리더 1개 (MAIN 3/12)

정도 차이가 있었던 것:
- 효율 주장을 측정하지 않음: ARXIV 8/12이고, MAIN은 9/12가 측정했다.
- 절제가 자기 주장과 모순됨: ARXIV 5/12이고, MAIN에서 명시된 사례는 1편이다.

주의할 점이 둘 있다.
- ARXIV-ONLY는 "미게재"일 뿐이다. 제출하지 않은 논문이 섞여 있을 수 있다.
- 위 대응은 상관 관찰이고 인과가 아니다.

## 5. 주의

- H1–H17은 계속 무효다. 특히 다음을 이유로 감점하지 않는다: 너무 단순함(H7), 선행 문헌 없이 새롭지 않다고 하기(H3), 추가 실험 요구를 reject 사유로 쓰기(H13), Limitations 항목을 그대로 약점으로 나열하기(H16), 주장과 무관한 폐쇄형 모델 비교 요구(H14).
- 저자가 SOTA를 주장하지 않았다면 "SOTA가 아니다"는 사유가 아니다(H5). 위 기준의 "이득"은 저자가 실제로 한 주장의 범위에서 본다.
- 심각도를 보정한다.
  - major는 핵심 주장을 무효화할 때만 붙인다.
  - Soundness 2 이하이면 3 이상을 주지 않는다.
  - 낮은 점수는 본문에 적은 구체적 결함으로 뒷받침해야 한다(I3).
  - 무작위 제출물의 절반 이상에 4를 주면 너무 관대한 것이다.
- 위 표의 편수는 묶음당 12편(COLING 6편)이라 표본이 작다. 경계 판정에서는 공식 기준(soundness·reproducibility → 3, novelty·impact → 4)을 우선한다.
